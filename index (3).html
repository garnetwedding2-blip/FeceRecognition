How do I get a Client ID?
  1. Open Google Cloud Console → create a project.
  2. APIs & Services → Library → enable Google Drive API.
  3. OAuth consent screen → External → add yourself as a test user.
  4. Credentials → Create credentials → OAuth client ID → Web application.
  5. Add http://localhost:8000 under Authorized JavaScript origins.
  6. Paste the Client ID above. Only the read-only Drive scope is requested.
